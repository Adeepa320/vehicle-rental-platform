## I. Launch sequence (day of)

1. Freeze: release commit tagged; A1–A8 green on it.
2. `pnpm production:check --env-file … --web-env-file … --live` → no FAIL.
3. Snapshot the database; run the migrator from the new image; verify the migration count (DEPLOYMENT.md §4).
4. Deploy api → worker → web; smoke: `/api/v1/health`, `/api/v1/ready`, home page, admin login with MFA, `/admin/system` healthy, one search, one quote.
5. PayHere: first live payment on a real booking (E3); confirm `payment_events` shows `signature_valid = true` and the booking is `confirmed`; record one refund (E3).
6. Monitor 30 minutes (G1–G3); then announce to the onboarded providers.
7. Record the launch in `INCIDENT_RESPONSE.md` §10 format (date, versions, who) and update the risk register.
