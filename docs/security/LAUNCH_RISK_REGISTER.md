# Launch risk register

**Status:** v0.1 (2026-10-18), Phase 10. Owner: founder (business and legal rows), engineering (technical rows). Review at every go-live meeting and after every incident; close a row only with evidence.
**Scope:** risks that remain after the Phase 10 work, for the validation launch on the South Coast (five towns, 20–40 vehicles, one API replica, one worker). Rows marked **EXTERNAL GATE — NOT EXECUTED** cannot be closed from the code base; rows marked **decision needed** wait for the user / founder. Nothing here is legal advice.
**Related:** [ASVS_V5_L1_ASSESSMENT.md](ASVS_V5_L1_ASSESSMENT.md), [DATA_RETENTION.md](DATA_RETENTION.md), [../runbooks/GO_LIVE_CHECKLIST.md](../runbooks/GO_LIVE_CHECKLIST.md), [../SECURITY_AND_PRIVACY.md](../SECURITY_AND_PRIVACY.md) §15, [../DEPLOYMENT.md](../DEPLOYMENT.md), [../TECH_DECISIONS.md](../TECH_DECISIONS.md) D67–D73.

Scales: likelihood L / M / H; impact L / M / H (H = money, personal data, legal exposure or the booking promise).
